## 1. instalação rápida

para utilizar da instalação rápida programada para o projeto, é necessário compreender que as únicas que possuem uma certeza de 100% de funcionamento são as da tabela 1. para instalar modelos locais que não estão mencionados na tabela, é preciso pesquisar em fontes oficiais

**modelos suportados:**

| comando do modelo | modelo base oficial | foco principal | VRAM recomendada |
| :--- | :--- | :--- | :--- |
| `qwen3-14b` | Qwen 3 (14B) | bom em código | ~10GB |
| `qwen2.5-7b` | Qwen 2.5 Coder (7B) | leve, muito rápido para terminal | ~5GB |
| `deepseek-7b` | DeepSeek Coder (7B) | raciocínio lógico e algoritmos complexos | ~5GB |
