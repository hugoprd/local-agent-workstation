## 1. quick installation

to use the quick installation programmed for the project, it is necessary to understand that the only ones with a 100% guarantee of working are those in table 1. to install local models that are not mentioned in the table, you must research official sources

**suported models:**

| model command | official base model | main focus | recommended VRAM |
| :--- | :--- | :--- | :--- |
| `qwen3-14b` | Qwen 3 (14B) | good at coding | ~10GB |
| `qwen2.5-7b` | Qwen 2.5 Coder (7B) | lightweight, very fast, fast for terminal | ~5GB |
| `deepseek-7b` | DeepSeek Coder (7B) | logical reasoning and complex algorithms | ~5GB |
